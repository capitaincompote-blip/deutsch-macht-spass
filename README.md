# 🇩🇪 Deutsch macht Spaß!

A playful German course for complete beginners (A1), taught in English, built as an installable web app.

**▶ Open the app: https://capitaincompote-blip.github.io/deutsch-macht-spass/**

- 17 short chapters (sounds, greetings, numbers, der/die/das, verbs, questions, family, time, café, hobbies, modal verbs…), a final exam and a printable cheat sheet
- Audio for every word, memory hooks, flashcards, matching, listening and typing games, quizzes and badges
- **Memory Book**: about 300 A1–A2 words as flip cards
- **My words**: add your own vocabulary, sort it into categories, export / import it
- Review deck with spaced repetition; progress is saved on your device

## Install on Android
Open the link in Chrome → menu ⋮ → **Install app**. It gets its own icon, opens full screen and works offline.

On iPhone: open the link in Safari → Share → **Add to Home Screen**.
